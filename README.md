# Доповіді → Excel

Веб-додаток: вставляєш текст доповідей пачкою — отримуєш XLSX.

## Запуск локально

```bash
python3 webapp.py
```

Потім відкрий у браузері: http://127.0.0.1:8099/

На macOS можна просто двічі клікнути `START.command`.

## Формат вхідного тексту

Нова доповідь починається з рядка, що містить ключ `Дата`. Далі йдуть
рядки виду `Ключ: значення` у будь-якому порядку.

Розпізнавані поля:

| Поле | Опис |
|---|---|
| Дата | дата події |
| Час | час події |
| № цілі | номер цілі |
| Результат | результат роботи |
| Н.П. | населений пункт |
| Обл. | область |
| Підрозділ | підрозділ |
| Позивний | позивний |
| Зброя | зброя/засіб |
| Висота | висота |
| Опис | опис події |
| Коментар | коментар |

Рядки обліку боєприпасів мають вигляд:

```
Набій <калібр> мм (<платформа>) - <кількість>
```

## Вивід

XLSX з двома аркушами:

- **Доповіді** — один рядок на доповідь
- **Набої** — один рядок на кожен тип боєприпасу

## Вимоги

Python 3 для локального сервера. Для веб-версії в браузері — нічого.

## Обмеження

- поле `Опис` не розбите на окремі колонки
- дати зберігаються текстом
- немає накопичення між запусками
- немає захисту від дублів
