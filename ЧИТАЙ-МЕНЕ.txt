ДОПОВІДІ → EXCEL
================

ЯК ЗАПУСТИТИ
-----------
1. Розпакуй цю теку (якщо архів).
2. Двічі клікни START.command
3. Відкрий у браузері: http://127.0.0.1:8099/
4. Вставляй текст доповідей у поле, натискай кнопку.

Якщо macOS не дає запустити START.command:
  правий клік → Open → Open
  (це стандартний захист macOS для нових скриптів)

ЩО ПОТРІБНО
-----------
- Python 3 (у macOS є вбудований, або з python.org)
- Нічого встановлювати не треба — тільки стандартна бібліотека

ЩО ВМІЄ
-------
- Вставляєш пачку доповідей одним текстом
- Кожна доповідь починається з рядка "Дата:"
- Отримуєш XLSX з двома аркушами:
  * "Доповіді" — один рядок на доповідь
  * "Набої" — один рядок на кожен тип набою

ОБМЕЖЕННЯ (поки)
----------------
- "Опис" не розбитий на окремі колонки
- Дати зберігаються текстом
- Немає накопичення між запусками
- Немає захисту від дублів

ФАЙЛИ
-----
START.command     запуск (двічі клікнути)
webapp.py         веб-сервер
report2xlsx.py    парсер + генератор XLSX
